1APIM gateway host

The only public front door. Foundry itself has no public IP, so the Bot Channel Service can only reach the agent through this APIM hostname (TLS + validate-jwt).

2/bot/agents — the API

Routes to the “Foundry Bot Bridge” API (apiId=foundry-bot, path bot). All agent messaging operations live under it.

3Agent slug — the switch

Selects the per-agent APIM operation. This segment decides native vs. custom: its policy is what forwards to the shared translator container (or, for a -restapi agent, straight to Foundry).

4/messages — the POST

The activity-delivery operation. The Bot Channel Service POSTs each Teams message here with a Microsoft-signed Bot JWT.
