Decoding a generalized bot messaging endpoint

An example Bot Service Messaging endpoint when there is no API Management layer. The public router and TLS proxy can be a firewall, load balancer, CDN, Application Gateway, or another network appliance.

1Public hostname

A hostname you control, with DNS resolving to the public entry point. It does not reveal or expose Foundry's private IP. The router can select a private destination by hostname, listener, path, or routing rule.

2Message path

A simple stable path for Bot Channel Service POSTs. It is only an example: the public endpoint can use any path convention that the routing component and Bot Service registration agree on.

3Routing decision

The routing rule, not the URL format, decides whether traffic reaches Foundry's native activityProtocol endpoint or a private translator container.
