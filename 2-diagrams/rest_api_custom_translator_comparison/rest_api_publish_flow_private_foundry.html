Return path: Foundry response travels back through the same ingress and Bot Channel Adapter to the user.
Private endpoint caveat: the Azure Bot Service and Microsoft channel adapters cannot reach a private IP directly. Public ingress, valid TLS, route/DNAT, and restricted source access are part of the runtime design.
What disappears versus the shared-router route: no custom translator container, per-agent routing registry, generated sideload package, or custom Bot Framework middleware. Foundry owns the activity protocol and catalog publication.
